Qué es CSS y para qué sirve

HTML define qué elementos existen. CSS define cómo se presentan esos elementos. El navegador construye primero la estructura HTML y después aplica las reglas CSS que coinciden con cada elemento.

HTML Define títulos, párrafos, botones, imágenes, formularios y secciones.
CSS Define colores, tamaños, espacios, bordes, posiciones y distribución.
JavaScript Añade comportamiento, lógica e interacción. No es necesario para aplicar estilos básicos.
HTML sin CSS
<h1>Mi proyecto</h1>
<p>Esta es una página web.</p>
<button>Conocer más</button>
CSS que modifica ese HTML
h1 {
  color: #2f6fed;
}

p {
  font-size: 18px;
}

button {
  background-color: #2f6fed;
  color: white;
}
Idea central para la clase: CSS no crea el contenido. CSS selecciona contenido que ya existe y cambia su presentación.

La sintaxis de una regla CSS

Una regla CSS responde tres preguntas. A quién se aplica, qué característica se modifica y qué valor tendrá esa característica.

Selector
El elemento que quiero modificar.
Propiedad
La característica que quiero cambiar.
Valor
El resultado que quiero aplicar.
p {
  color: blue;
  font-size: 18px;
}
pEs el selector. La regla buscará todos los elementos <p>.
{ }Las llaves contienen todas las declaraciones de estilo que pertenecen a esa regla.
colorEs una propiedad CSS. En este caso controla el color del texto.
blueEs el valor asignado a la propiedad color.
;Finaliza una declaración. Es buena práctica escribirlo siempre.
3

Cómo se conecta CSS con HTML

Existen tres formas. Para proyectos reales se recomienda una hoja de estilos externa porque separa la estructura de la presentación y permite reutilizar el mismo CSS.

CSS externo La práctica recomendada. El HTML enlaza un archivo .css desde <head>.
CSS interno Las reglas se escriben dentro de <style>. Es útil para ejercicios pequeños.
CSS en línea Se escribe en el atributo style. Conviene evitarlo en proyectos mantenibles.
Forma recomendada
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Mi proyecto</title>

  <link rel="stylesheet" href="estilos.css">
</head>
rel="stylesheet"Le indica al navegador que el archivo enlazado es una hoja de estilos.
href="estilos.css"Indica la ubicación del archivo CSS que debe cargar el navegador.
<head>Es la zona del documento donde se enlazan hojas de estilo y se declaran metadatos.

Pseudo-clases. Estilos que dependen del estado

Una pseudo-clase no busca otro elemento HTML. Selecciona un elemento que ya existe cuando cumple una condición: el mouse está encima, tiene el foco, está marcado, ocupa cierta posición o se encuentra deshabilitado.

Forma general
selector:pseudo-clase {
  propiedad: valor;
}

/* Ejemplos */
a:hover { color: #b42318; }
input:focus { outline: 3px solid #2f6fed; }
input:checked + span { font-weight: 700; }
li:first-child { background: #eaf2ff; }
li:nth-child(2n) { background: #f3f6fa; }
No confundas pseudo-clase y pseudo-elemento

:hover describe un estado del elemento existente.

::before y ::after crean una caja generada que se comporta como una parte adicional del elemento.

Cascada, especificidad y herencia

Varias reglas pueden intentar modificar la misma propiedad del mismo elemento. CSS necesita decidir cuál gana. Esa decisión forma parte de la cascada.

CascadaDetermina qué declaración termina aplicándose cuando existen reglas que compiten.
EspecificidadUn selector por ID pesa más que una clase, y una clase pesa más que un selector de elemento.
HerenciaAlgunas propiedades como color y font-family pasan del padre a los hijos.

Colores en CSS

Un mismo color puede escribirse de varias formas. HEX es compacto, RGB expresa componentes de rojo, verde y azul, y HSL expresa matiz, saturación y luminosidad.

Ejemplos equivalentes
.caja {
  background: #2f7bb8;
}

.caja {
  background: rgb(47, 123, 184);
}

.caja {
  background: hsl(207, 59%, 45%);
}

Variables CSS

Las variables permiten guardar un valor con un nombre y reutilizarlo. Esto evita repetir colores, radios o espacios en decenas de reglas.

Código
:root {
  --color-primario: #2f6fed;
  --espaciado: 18px;
  --radio: 16px;
}

.tarjeta {
  background: var(--color-primario);
  padding: var(--espaciado);
  border-radius: var(--radio);
}

Mobile-first y breakpoints. Diseñar desde el espacio mínimo

Mobile-first no significa crear una versión móvil separada. Significa que las reglas base funcionan en el ancho más pequeño y los @media (min-width: ...) agregan o sobrescriben propiedades cuando el diseño dispone de más espacio.

BaseTeléfonoSin media query
Primer corteTabletmin-width: 768px
Segundo corteEscritoriomin-width: 1024px
CSS mobile-first
/* 1. Base. Se aplica a todos los anchos */
.galeria {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

/* 2. Desde 768px se sobrescribe una propiedad */
@media (min-width: 768px) {
  .galeria {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* 3. Desde 1024px se vuelve a sobrescribir */
@media (min-width: 1024px) {
  .galeria {
    grid-template-columns: repeat(3, 1fr);
  }
}
La cascada sigue funcionando

A 500px solo coincide la regla base.

A 800px coinciden la base y el primer @media. La regla de dos columnas sobrescribe la propiedad anterior.

A 1100px coinciden las tres. La última regla aplicable establece tres columnas.

Qué es realmente un breakpoint

Un breakpoint es el ancho donde tu diseño necesita cambiar. Valores como 576px, 768px, 992px, 1024px y 1200px son referencias frecuentes, pero no constituyen una obligación de CSS.

CSS y accesibilidad

Un diseño no está terminado solo porque se ve bien. Debe conservar contraste suficiente, foco visible y tamaños legibles para diferentes personas y dispositivos.

Contraste El texto debe diferenciarse claramente del fondo. Un gris demasiado claro puede ser ilegible.
Foco Quien navega con teclado necesita ver qué enlace, botón o campo está activo.
Responsive El contenido debe poder leerse sin zoom excesivo ni desplazamiento horizontal innecesario.
Evitar
a:focus {
  outline: none;
}
Mejor
a:focus-visible,
button:focus-visible {
  outline: 3px solid #2f6fed;
  outline-offset: 3px;
}
