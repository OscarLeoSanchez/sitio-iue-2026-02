Cuatro tropiezos al empezarRevísalos si no compila
  • Una línea incompleta, como app.MapGet("Productos/{id}"); sin función, impide compilar. Complétala o bórrala.

Etapa 9: Ciclos de vida

Cuánto dura cada instancia

SingletonUna para toda la aplicación
El contenedor la crea una vez y todas las peticiones la comparten.
La balanza del mercado: una sola para todos los puestos.
ScopedUna por petición
Dentro de una misma petición todos reciben la misma; la siguiente petición trae una nueva.
El recibo de cada cliente: igual para toda su compra, distinto para el siguiente.
TransientUna nueva cada vez
Cada quien que la pide recibe una instancia nueva, incluso dos veces en la misma petición.
Una bolsa nueva por cada producto que se empaca.

Errores frecuentes

Un campo sin nameEl formulario no lo envía
El id no sirve para eso. Escribe name="cantidad" en cada campo.
fetch con JSON sin Content-TypeEl servidor responde 415
Agrega headers: { 'Content-Type': 'application/json' }.
Quitar DisableAntiforgery en la etapa 6El primer POST responde 500
Un formulario de wwwroot no trae el token. Déjalo en la etapa 6; con Razor, el token llega solo.
Una vista con el nombre equivocado500 y la consola dice que no la encuentra
Carpeta con el nombre del controlador y archivo con el nombre del método: Views/Catalogo/Index.cshtml.
Olvidar registrar un servicioFalla al pedir, no al arrancar
Agrega la línea AddSingleton<IPedidos, PedidosEnMemoria>() y revisa la consola: dice qué tipo no pudo resolver.
Pedidos con AddScopedPOST 201 y después una lista vacía
Un servicio que guarda estado compartido es AddSingleton.
Un middleware que olvida nextNingún paso siguiente ve la petición
Llama await next(context) salvo cuando quieras cortar a propósito, como la puerta de /admin.
El orden del pipelineArchivos antes del registro: sin línea
Pon primero lo que debe verlo todo. Si la puerta va antes que el registro, tampoco anota los 401.
