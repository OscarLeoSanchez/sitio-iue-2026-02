innerHTML += reconstruye todo

El primer li tiene un manejador de clic. Ejecutas lista.innerHTML += ... y haces clic en ese li. ¿Qué pasa?

Parte 6. El ES6 que necesitas

const fija la etiqueta, no el cajón

const producto = { cantidad: 12 };
producto.cantidad = 0;       // A
producto = { cantidad: 5 };  // B

¿Cuál de las dos líneas, A o B, da error?

const impide reasignar el nombre, no cambiar el objeto. La B lanza TypeError.

Alcance

Cada variable vive en su bloque

for (const producto of productos) {
  const mensaje = `Hay ${producto.cantidad}`;
  console.log(mensaje);   // aquí existe

console.log(mensaje);     // fuera del for
console.log(total);       // antes de declararla

const, let y varReasignar y alcance
const: no se reasigna, vive en su bloque. let: se reasigna, vive en su bloque. var: se reasigna y vive en la función completa; es la forma antigua.
Si lees let, ese valor cambia en algún punto. Si no cambia, usa const.
