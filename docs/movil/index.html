Criterios de desempeño

Toda rúbrica del curso se traza a uno de estos tres criterios de la carta descriptiva:

  • Conocimiento. Describe los fundamentos del desarrollo móvil, la arquitectura básica de Flutter, el lenguaje Dart y el flujo de trabajo con Git.
  • Desempeño. Desarrolla aplicaciones móviles con Flutter, integrando navegación, consumo de APIs REST y persistencia local, aplicando principios de arquitectura de software y experiencia de usuario.
  • Producto. Implementa aplicaciones móviles integrando interfaz, lógica de negocio, persistencia, servicios externos y capacidades inteligentes.
