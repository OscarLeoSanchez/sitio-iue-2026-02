¿Cómo se borra solo una fila?

Borrar con where y whereArgs

Future<void> borrarFavorito(Database db, int id) async {
  await db.delete('favoritos', where: 'id = ?', whereArgs: [id]);
}
El ? del where se reemplaza con el valor de whereArgs, que viaja aparte.
No pegues el valor dentro del texto del where: un nombre con comillas rompe la sentencia. Usa siempre ? y whereArgs.

¿Cómo pasa un objeto Dart a una fila y de vuelta?

toMap y fromMap: ida y vuelta

  // bool en Dart, 0 o 1 en SQLite
  Map<String, Object?> toMap() {
    return {
      'id': id,
      'nombre': nombre,
      'precio': precio,
      'disponible': disponible ? 1 : 0,
    };
  }
  factory Producto.fromMap(Map<String, Object?> mapa) {
    return Producto(
      id: mapa['id'] as int,
      nombre: mapa['nombre'] as String,
      precio: mapa['precio'] as int,
      disponible: mapa['disponible'] == 1,

  }

El Map lleva una clave por cada columna de la tabla productos.

¿Qué pasa si el guardado falla a la mitad?

Todo o nada: una transacción

Future<void> guardarProductos(Database db, List<Producto> productos) async {
  await db.transaction((txn) async {
    final lote = txn.batch();
    lote.delete('productos');
    for (final p in productos) {
      lote.insert('productos', p.toMap());
    }
    await lote.commit(noResult: true);
  });
}

Una transacción aplica todos los cambios o ninguno. El batch los junta para enviarlos de una vez.

¿Cómo se usa flutter_secure_storage?

Guardar, leer y borrar un token

  Future<void> escribir() async {
    await almacen.write(key: 'token', value: 'token-de-prueba-123');
    await leer();
  }
  Future<void> leer() async {
    final guardado = await almacen.read(key: 'token');
    setState(() => token = guardado);
  }
  Future<void> borrar() async {
    await almacen.delete(key: 'token');
    await leer();
  }

almacen es un FlutterSecureStorage. Es el mismo patrón de preferencias: escribir, leer y borrar por clave.

En Android la llave vive en el Keystore; en iOS el dato va al Keychain.

¿Qué significa cada mensaje y cómo se arregla?

Errores frecuentes

no such table: productosDesinstala la app o sube version y migra.
Cambiaste onCreate, pero el archivo de la base ya existía: onCreate no vuelve a correr y la tabla nueva nunca se crea.
near "SELEC": syntax errorCorrige la palabra que señala el mensaje.
La sentencia SQL está mal escrita. SQLite dice dónde dejó de entender: justo en SELEC.
database_closedNo uses db después de db.close().
El objeto Database ya se cerró. Abre la base una vez y úsala mientras la app la necesite.
UNIQUE constraint failed: productos.idNo insertes dos veces el mismo id.
La clave primaria no se repite. Con guardarProductos la transacción se deshace y la tabla queda como estaba.
Instance of 'Future<List<Producto>>'Escribe await antes de leerProductos(db).
Sin await imprimes el Future, no la lista. Si lo usas como lista, flutter analyze marca el error antes de correr.

En un teléfono el mensaje trae más texto alrededor, pero la frase de SQLite es la misma.
