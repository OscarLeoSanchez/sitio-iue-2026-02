Eventos

Un clic es una señal que puedes escuchar

Cuando alguien pulsa Agregar, el navegador crea un evento y llama a cada escuchador registrado en ese nodo. Tu función recibe el evento como parámetro.

const boton = document.querySelector('#agregar');
boton.addEventListener('click', (evento) => {
  console.log(evento.type); // 'click'
  console.log(evento.target); // el botón pulsado
});
addEventListenerRegistra una función sin borrar a las demás
Le pide al navegador que llame a tu función cada vez que ocurra ese tipo de evento sobre ese nodo. Puedes registrar varias funciones para el mismo evento.
boton.addEventListener('click', agregar);
Escribir agregar() con paréntesis: la función se ejecuta en ese instante y se registra su resultado.
PropagaciónEl evento sube del hijo hasta el documento
Después de ocurrir en un nodo, el evento sube por sus ancestros: li, ul, section, body. Por eso un solo escuchador en la lista puede atender el clic de cualquier producto.
Una noticia en la vereda: primero la sabe el vecino, después la junta y al final todo el pueblo.
lista.addEventListener('click', (e) => e.target.closest('li'));
preventDefault()Cancela la acción automática del navegador
Evita, por ejemplo, que un formulario recargue la página al enviarse. No detiene la propagación del evento.
form.addEventListener('submit', (e) => e.preventDefault());
Confundirlo con stopPropagation(), que es el que detiene la subida del evento.
Es como el timbre de la finca: no vigilas la puerta todo el día; instalas el timbre y reaccionas cuando suena.

¿Cuántos productos cuenta items?

// La lista #canasta tiene 3 elementos li
const lista = document.querySelector('#canasta');
const items = document.querySelectorAll('#canasta li');

const nuevo = document.createElement('li');
nuevo.textContent = 'Panela';
lista.append(nuevo);

console.log(items.length);
console.log(lista.children.length);

La lista empieza con 3 productos. ¿Qué imprime la primera línea de consola?

querySelectorAll devuelve una NodeList estática: una foto de la lista en ese momento. Por eso imprime 3. En cambio, lista.children es una HTMLCollection viva y la segunda línea imprime 4.

Cada línea tiene su momento

async function cargarProductos() {
  try {
    const res = await fetch('/api/productos');
    if (!res.ok) throw new Error('HTTP ' + res.status);
    const productos = await res.json();
    pintar(productos);
  } catch (error) {
    mostrarError(error);
  }
}
function cargarProductos() {
  fetch('/api/productos')
    .then((res) => {
      if (!res.ok) throw new Error('HTTP ' + res.status);
      return res.json();
    })
    .then((productos) => pintar(productos))
    .catch((error) => mostrarError(error));
}
